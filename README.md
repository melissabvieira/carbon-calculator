# Calculadora de Pegada de Carbono 🌱

Projeto desenvolvido para o bootcamp da DIO, utilizando HTML, CSS e JavaScript, com apoio do GitHub Copilot durante a implementação.

## Sobre o projeto

A Calculadora de Pegada de Carbono permite estimar a emissão de CO₂ gerada por diferentes meios de transporte. O objetivo é conscientizar sobre o impacto ambiental dos deslocamentos e incentivar escolhas mais sustentáveis.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- GitHub Copilot

## Funcionalidades

- Seleção do meio de transporte
- Inserção da distância percorrida
- Cálculo estimado da emissão de CO₂
- Exibição do resultado de forma simples e clara

## Objetivo

O projeto foi criado como prática de desenvolvimento front-end, aplicando conceitos de estrutura HTML, estilização com CSS e lógica de programação com JavaScript.
